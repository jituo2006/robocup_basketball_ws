# 01 · 离线验证（不需要任何硬件）

**目的**：在碰硬件之前，先把"软件链路本身"验证完。
这样上车时出的问题，就只可能是硬件/参数，而不是代码。

---

## 0. 一条命令跑完（推荐）

```bash
cd /home/user/robocup_basketball_ws
./tools/check_all.sh
```

它会先跑离线验证（8 项），再跑上车预检，最后给出结论。

也可以分开跑：

```bash
python3 tools/verify_offline.py     # 只做离线验证
./tools/preflight.sh                # 只看硬件侧还差什么
python3 tools/verify_offline.py --only vision,chassis   # 只跑某几项
```

### 离线验证的 8 项

| # | 检查 | 它在验证什么 |
|---|---|---|
| 1 | 构建完整 | 7 个包 + 关键入口齐全 |
| 2 | 视觉检测 | 合成图上 5 类目标全检出、无误检 |
| 3 | 底盘运动学 | `vx=0.5 → ±34 rpm`，符号与幅值都对；**停发后 200ms 归零**（安全网） |
| 4 | 机构节点健壮性 | 无串口时不崩溃、优雅降级、服务返回明确错误 |
| 5 | EKF 数值 | 直行/转向预测正确、位姿更新收敛 |
| 6 | 状态机全流程 | 能走到 `LAUNCH`（含 8 秒规则启动延迟） |
| 7 | 整车离线启动 | 6 进程全起，odom/detections/pose 全链路有数据 |
| 8 | 关机安全性 | Ctrl+C 无 Traceback / RCLError / 段错误 |

> **8/8 通过 = 软件链路已就绪**，剩下的红项只可能是硬件。

> `failed to create symbolic link ... Is a directory`，
> 说明上一次非 symlink 构建留了真实目录挡路。解法：
> ```bash
> rm -rf build/<包名> install/<包名>
> colcon build --symlink-install --packages-select <包名>
> ```

## 3. 验证底盘运动学（dry_run，不发 CAN）

```bash
# 终端1
ros2 run rb_chassis rb_chassis_node --ros-args -p dry_run:=true
# 终端2
ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5}}"
ros2 topic echo /chassis/wheel_speed
```

**预期**：`data: [33, 33, -33, -33]`

手算核对（`wheel_radius=0.10, width=length=0.40, ratio=1`）：

```
factor = 60/(2π·0.1) = 95.49
每轮 = vx · cos45° · factor = 0.5 × 0.7071 × 95.49 ≈ 33.8
前两轮同号、后两轮反号（X 型全向轮直行）
```

**这一步在验证什么**：运动学公式、参数单位、符号。**不用 CAN、不会动车。**

## 4. 验证弹射机构节点不崩（没有串口也不会崩）

```bash
ros2 run rb_launcher rb_launcher_node
```

**预期**：打印 `打开机构串口失败 ... 节点继续运行`，然后每 2 秒重试一次。
**关键**：进程**不能退出**。原版 `R1_server` 在这里会 abort。

```bash
ros2 topic echo /rb_launcher/ok       # data: false
```

## 5. 验证状态机全流程（假底盘 + 假检测）

```bash
# 终端1
ros2 launch rb_bringup bringup_fsm_test.launch.py

# 终端2
ros2 service call /rb_mission/set_mission rb_msgs/srv/SetMission "{mission: PASS}"
ros2 topic echo /mission/status
```

**预期迁移顺序**（本机实测，约 40 秒走完一次动作）：

```
IDLE → START_DELAY（8 秒，规则要求）
     → SEEK_BALL                      接近目标球
     → ACQUIRE                        球在近距离消失（贴上去后移出视野）
     → NAV_TO_ZONE                    前往动作区
     → ALIGN                          对准传球架圆环
     → LAUNCH                         调用发射
     → SEEK_BALL                      第 2 次动作
```

**这一步在验证什么**：状态迁移、定位闭环、区域判定、速度输出、服务调用。
**不验证**：真实视觉、真实底盘、真实机构。
