# 当前路线非必要门槛清理

2026-10-15。作用范围：`tools/test_perimeter_ball.py` 的 Runner，覆盖 fixed、first-pass、三个回合共用的行驶、取球和回位。行驶/取球/回位是动作功能，下面明确记录本次从它们内部删除的检查；不是删除这些功能。先前只默认禁用的总时限与本次实际删除的分支分开记载。

## 当前路线保留的必要条件

|函数/模块|触发条件及默认参数|保留原因/调整接口|
|---|---|---|
|Runner.require_fresh_pose / _on_pose|行驶位姿缺失、非有限数、源年龄超过1秒，或源时间戳非法/倒序；重复帧不刷新源时间|位置反馈失效不能继续计算位移；`--pose-timeout`可调|
|Runner._on_pose|平移跳变超过0.25m+1.0m/s×帧间隔，记录motion_fault|防止错误位置造成错误方向和行程；`--pose-jump-margin`、`--pose-max-speed`可调，故障仍须重开/初始化|
|ProgressWatchdog|有运动指令但误差连续10秒没有足够改善|防止卡住后持续驱动；`--motion-stall-seconds`可调，不是正常动作总时限|
|goto / rotate_to / rear_distance_scoop / scan_to|目标位置、角度或距离进入配置容差就停车|这是结束动作的判据，删除会越过目标；`--tol`、`--yaw-tol`、`--step-tol`可调|
|centered_target_candidates|球种、来源、合法框、置信度、检测源时效和当前居中容差|避免把旧球框或干扰球当成目标；检测时效、置信度及中心容差可调|
|aligned_intake_approach / intake_text / release|靠近失败、服务无响应、机构指令失败、正式传球转向未完成|失败后不自动跨入后续机构动作，避免重复/错误发射；不会把未执行当作成功|
|底盘/控制入口|急停、速度指令失联、非有限指令、设备协议错误、实际速度/加速度限幅、同时存在两个运动控制源|防止失联后继续运动、错误驱动和控制冲突；未删除|

固定角度传球仍使用`release.pass.aim_mode=fixed`、`search_heading_deg=49`，无需aim坐标和前摄对柱。路线的旧固定动作总时限仍不参与运动退出。

## 范围与验证边界

本轮没有把独立的MissionNode/ArrivalGate、定位滤波、检测算法、投篮对柱、相机硬件、规则计分中的所有限制一并声称删除。三回合脚本通过Runner行驶，不经过MissionNode的导航到位确认。独立mission启动时仍有自己的到位/定位条件；历史剩余表应按本记录修正，不能把它当当前路线行为。

测试使用源时间戳模拟数据，覆盖即时到点、即时到角度、单帧后摄居中、定位新鲜时原始odom过期仍可继续、无效定位停车、故障取消停车、无进展停车、取球完成和三回合闭环。额外检验兼容参数不再拦截启动，速度上限放开后仍拒绝NaN/Inf/非正数。本地不具备ROS运行时，ROS启动、串口及导航集成测试不计为本轮本机通过结果；同步NUC后另外执行无硬件测试。未以测试结果宣称实车动作或球已入仓/发射成功。
