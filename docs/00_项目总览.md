# 00 · 项目总览与快速开始

RoboCup 篮球机器人 · 自主机器人项目（继承 ROBOCON 2025 篮球代码，重写为 ROS 2 Humble）。
仓库：`~/robocup_basketball_ws`。

> 本目录按**模块**划分文档，每个模块一篇：
> `01 相机` → `02 感知` → `03 底盘` → `04 机构` → `05 定位` → `06 任务` → `07 整车联调` → `08 已知限制`。

---

## 1. 包结构（9 个包）

| 包 | 职责 | 关键产物 |
|---|---|---|
| `rb_msgs` | 消息/服务接口 | `Detection` `DetectionArray` `RobotState` `MissionStatus` `Launch.srv` `GotoPose.srv` |
| `rb_camera` | UVC 相机驱动 | `/camera/image_raw`（原始）`/compressed`（JPEG，实际用）`/camera_info` |
| `rb_perception` | 视觉检测 | `/perception/detections`（YOLO + HSV/霍夫圆） |
| `rb_chassis` | 全向底盘 | 订阅 `/cmd_vel`，输出 `/chassis/wheel_speed` |
| `rb_launcher` | 弹射机构 | `Launch.srv`（发射/夹爪/滑轨） |
| `rb_localization` | 定位（EKF 融合） | `/localization/pose` `/localization/ok` |
| `rb_mission` | 任务状态机 | `/mission/status` `/mission/state` `GotoPose.srv` |
| `rb_bringup` | 整车启动 | `bringup_full.launch.py` 等 |
| `rb_tests` | 测试基建 | `ws.py`、fakes、checks、离线验证 |

数据流（简化）：

```
相机 ──JPEG──▶ 感知(YOLO/HSV) ──detections──▶ 任务状态机 ──cmd_vel──▶ 底盘 ──CAN──▶ 电机
                 │                                ▲                        │
                 └────────── 定位(EKF) ◀── odom/雷达/视觉方位角 ────────┘
```

## 4. 环境约定

- **venv 隔离**：`~/yolo_env` 装 torch/ultralytics/onnx（训练/导出用），**不用于 ROS**；
  系统 python 保持 numpy 1.21.5 / cv2 4.5.4 / setuptools 59.6（ROS 依赖）。
- **onnxruntime**：装在系统 python（`rb_perception` 推理需要）。
- **模型文件**：`~/models/ball.onnx`（2 类 YOLO，9.4MB），**在仓库外不入库**。
- **`.bashrc`**：`rbws` 进环境、`rbws build` 干净构建；`basketenv` 指向旧工程（勿混用）。
- **SSH 推送**：`~/.ssh/config` 里 `github.com` 走了本地代理（`ProxyCommand nc -X connect -x 127.0.0.1:7897`）。

## 5. 消息接口（`rb_msgs`）

- `Detection`：`label / confidence / bbox / px / py / bearing_rad / distance_m / diameter_m`
- `DetectionArray`：一帧的检测结果，发布在 `/perception/detections`
- `RobotState`：`x / y / yaw / vx / vy / wz`（yaw 本队约定塞在 position.z 里）
- `MissionStatus`：当前阶段 + 目标球类型
- `Launch.srv`：机构动作 `{action, speed, angle}`
- `GotoPose.srv`：`{x, y, yaw, align_yaw}` → 导航到点

## 6. 本工程相对 ROBOCON 代码的关键修改

1. **修了 3 个真实 bug**（见 `03_底盘模块` 和 `08_已知限制`）：
   限速的 `clamp` 返回值被丢弃、`limit_acc` 从未生效、CAN 发送队列无限积压（窜车元凶）。
2. **新增安全网**：`cmd_vel_timeout_ms=200` 收不到命令自动零速。
3. **新增 YOLO 感知**：自训 2 类（basketball/volleyball）替代纯 HSV。
4. **场地几何按 2025 规则填入**，并修正三分线圆心（见 `06_任务模块`）。
5. **测试工程化**：156 个单元测试 + 离线自检 8 项 + 上车预检。
