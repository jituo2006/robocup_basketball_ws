# 07 · 整车联调与排查

> **原则**：一次只点亮一层，每层验收通过再走下一层。
> 顺序：**底盘 → 机构 → 相机/感知 → 定位 → 整车**。各模块细节见 01~06。

---

## 1. 上车顺序（checklist）

```bash
rbws && ./tools/check_all.sh        # ① 出发前：离线 8/8 + 预检，失败项全是硬件才对
```

| 步 | 做什么 | 验收 | 详见 |
|---|---|---|---|
| 1 | CAN + 底盘 | 键盘遥控 6 方向对、松手即停 | `03` |
| 2 | 机构串口 | 夹爪/滑轨/发射能驱动、`/rb_launcher/ok=true` | `04` |
| 3 | 相机 + 感知 | `view_camera.py` 框对、无墙面误检 | `01` `02` |
| 4 | 定位 | 推车走一圈回原点误差 < 20cm | `05` |
| 5 | 整车空跑（不放球） | 状态迁移合理、车往合理方向走 | 本节 §3 |
| 6 | 放球逐阶段 | 每阶段单独确认 | 本节 §4 |

---

## 2. 整车启动

```bash
ros2 launch rb_bringup bringup_full.launch.py
```

分模块起：`rb_camera` `rb_perception` `rb_chassis` `rb_launcher` `rb_localization` `rb_mission`
各自都有 `launch/*.launch.py`。

---

## 3. 空跑任务（先不放球）

```bash
ros2 service call /rb_mission/set_mission rb_msgs/srv/SetMission "{mission: PASS}"
ros2 topic echo /mission/status
```

**急停（任何时候）**：

```bash
ros2 topic pub --once /mission/estop std_msgs/msg/Bool "{data: true}"
```

## 4. 放球逐阶段确认

| 阶段 | 不对时改哪里 |
|---|---|
| `SEEK_BALL` | `perception.yaml` 阈值；`mission.yaml` `max_linear` |
| `ACQUIRE` | `close_lost_distance_m`、`acquire_seconds` |
| `NAV_TO_ZONE` | `field.*_zone_target` |
| `ALIGN` | `kp_yaw`、`yaw_tolerance` |
| `LAUNCH` | `rb_launcher` 是否 ok、`speed/angle` |
| `RETURN_HOME` | `field.home` |

## 5. 排查树

```
车不动？
├─ 先跑 tools/can_recover.sh —— 它会查 can0 状态 + 清掉重复的底盘节点
│   （拔插过 CAN 适配器的话，大概率就是它，见 docs/03 §2.2）
├─ /cmd_vel 有数据吗 → 没有 = 遥控没起，或 /mission/status 卡在等定位/视觉
│                     （用 ros2 topic info /cmd_vel：Publisher 和 Subscription 都要是 1）
├─ 有数据不动      → ① can0 是 UP 吗（拔插后会变 DOWN）
│                     ② 是不是有多个底盘节点在抢 CAN
│                     ③ **电机板断电 10 秒再上电**（故障锁存只能靠断电清）
│                     判据：TX 错误计数 = 0 才算通信正常；RX=0 是正常的，别管
└─ 动但方向不对    → 尺寸参数没量对 / angular_z_sign 反了

定位飘？
├─ /localization/ok 是 true 吗
├─ landmarks 填了吗（空了视觉方位角不生效）
└─ 静止漂 → 里程计噪声大 或 绝对观测没生效

视觉看不到？
├─ /perception/detections 有对应 label 吗
│   ├─ 有目标没框 → 阈值/模型问题
│   └─ 看不到     → 相机曝光/视野，不是算法问题
└─ view_camera.py 里能看到吗
```
