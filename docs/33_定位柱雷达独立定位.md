# 定位柱雷达独立定位（2026-10-13）

摄像头未识别、观测过期、多个识别框、方向关联失败或相机未标定时，允许使用雷达独立定位。不会为了让摄像头看到定位柱而强制先旋转。视觉可靠时仍可辅助关联。

雷达先按柱半径、高度、弧长和拟合误差筛选，再按当前场地位置及朝向预测柱位置，关联已知定位柱（-3.725，5.75）。关联范围内必须只有一个候选；连续独立新点云稳定后才允许校正。重复、过期或不同步的点云不能通过。柱只约束平移，朝向仍使用已确认的定位基准。

配置入口为 tools/pillar_localization.json：

- lidar_fallback_enabled=true：开启摄像头漏检时雷达独立观测。
- lidar_landmark_gate_m=1.0：预测地标关联范围，允许在线改配置后下次运行读取。
- lidar_bearing_sigma_deg=0.5：雷达方向不确定度估计。
- lidar_paper_reference_confirmed=false：当前使用纸面替代物；仅在验证雷达拟合的纸面中心确实对应已知参考点后设为 true。

geometry_confirmed 和 heading_confirmed 保留原来的 false。没有真实标定证据时，不自动修改确认标记。纸面测距可诊断展示，但未确认的纸面中心不用于行驶定位；不加圆柱半径补偿。
