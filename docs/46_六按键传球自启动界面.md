# 六按键传球自启动界面

NUC 桌面显示 A/B 场地各回合 1/2/3，共六个动作按钮。页面沿用原控制台配色、大按键和输出面板，文件为 `tools/console_ui.html`。

## 执行方式

按钮直接启动 `bash tools/run_first_round.sh --start-point A|B`、`run_round2.sh` 或 `run_round3.sh`。起步 10 秒等待由原脚本配置执行，UI 不重复等待。原有机构指令、运动实现、脚本内部检查和 SSH 直接执行方式保留。

## 前后端分离与脚本更新

前端只提交 `side`（A/B）和 `round`（1/2/3），不包含脚本名、路径、参数或等待时长。后端通过 `tools/pass_actions.json` 将 A1/A2/A3/B1/B2/B3 映射成命令参数列表，每次点击重新读取配置。

- 修改原脚本内容或路线参数：保存后下次执行生效，前端不改，UI 服务无需重启。
- 更换脚本名称、路径或参数：只改 `pass_actions.json` 对应项，下一次点击立即使用新命令，前端不改，UI 服务无需重启。
- 修改 Python 后端代码：只重启 `robocup-pass-console.service` 加载代码，前端不改。

例如 A1 可改为 `["bash", "tools/new_round1.sh", "--start-point", "A", "--some-option"]`。路径相对于工作空间根目录，也可填写绝对路径。直接按参数列表运行，不通过 shell 拼接命令。更新映射文件时可先写临时文件再原子替换，避免读取半份 JSON。

固定接口：`POST /api/pass/run` 接收 `{"side":"A","round":1}`，返回 `{"id":"执行ID"}`；`GET /api/pass/state` 返回输出和状态。保持接口字段及 `idle/running/succeeded/failed` 状态含义即可独立更新后端实现。当前默认映射仍执行原六种组合，起步等待仍由路线配置保持为 10 秒。

UI 不执行硬件探测、就绪检查、确认弹窗、额外任务超时或按钮禁用判断。每次点击启动所选脚本；没有额外的并发拦截。页面显示当前所选执行记录的标准输出、标准错误、成功/失败和真实退出码，刷新页面会恢复该记录。

## NUC 安装与启动

```bash
cd /home/user/robocup_basketball_ws
bash tools/install_pass_console_autostart.sh
bash tools/open_pass_console.sh
```

安装创建用户服务 `robocup-pass-console.service` 和 `~/.config/autostart/robocup-pass-console.desktop`。后端在用户登录时启动，桌面自动用 Chrome 独立窗口显示 `http://127.0.0.1:8090`。NUC 目前配置的桌面登录会话会触发此入口。只启动 UI，不自动启动运动脚本或整套 ROS 节点。

手动启动后端：`bash tools/start_pass_console.sh`，或 `python3 tools/console_app.py --pass-only`。原综合控制台仍由 `bash tools/console.sh` 启动，页面保存在 `tools/console_debug_ui.html`；两者使用同一默认端口，请勿同时启动在 8090。

## SSH 返回结果

原脚本从 SSH 执行仍直接输出日志、返回退出码。UI 后端也提供相同执行记录，SSH 中可查询：

```bash
# 只读查询最近一次执行，不启动运动
curl -s http://127.0.0.1:8090/api/pass/state
```

结果含 `id`、`side`、`round`、`status`、`returncode`、`lines`。可用 `/api/pass/state?id=记录ID&after=游标` 增量读取。UI 触发接口为 `POST /api/pass/run`，JSON 为 `{"side":"A","round":1}`，收到执行 ID 后查询至结束即可；接口启动真实运动脚本。

## 验证边界

UI/分发/结果测试 13 项，镜像专项 83 项。测试使用模拟子进程，涵盖六种脚本映射、输出/错误输出、退出码、页面仅六按钮、重复点击不被新增 UI 条件拦截，以及 A/B 完整流程镜像。专项验证同一后端实例、相同 API 请求、前端 HTML 字节不变时，更换脚本路径及参数立即执行新脚本；更新原脚本内容也立即生效。部署核验只读访问页面和状态 API，不点击真实运动按钮、不重启机器人节点；未通过重启整机验证开机显示。
