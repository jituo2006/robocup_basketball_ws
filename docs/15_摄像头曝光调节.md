# 前后摄像头曝光调节

双摄画面下各有曝光滑块、数值输入、应用按钮和恢复自动曝光按钮。
范围、步长和当前值来自各摄像头的 V4L2 驱动，不受软件自动曝光的 min/max 限制。
没有曝光控制、没有出图或状态过期时，界面禁用该路控制。
应用手动值会关闭该路软件自动曝光；只有驱动写入及读回一致才报告成功。
调整在相机运行时生效，设备重连保留，节点重启后恢复配置文件设置。

HTTP 接口：`POST /api/action`，请求体：

```json
{"name":"CAMERA_EXPOSURE","args":{"slot":"rear","value":150}}
```

`slot` 为 `front` 或 `rear`。恢复自动曝光时将 `value` 替换为 `"auto":true`。
`GET /api/state` 的 `exposure` 字段返回两路曝光状态。
ROS 接口为相机节点的 `set_parameters_atomically` 服务，手动设置需同时提交
`exposure.auto=false` 和整数 `exposure.value`；自动模式提交 `exposure.auto=true`。
曝光状态发布到 `/camera/exposure`、`/camera_rear/exposure`（std_msgs/String JSON）。
曝光值是驱动原始单位，不能通用地当成毫秒。较大值通常提高亮度，也可能降低帧率。
