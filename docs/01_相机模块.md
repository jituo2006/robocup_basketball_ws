# 01 · 相机模块（rb_camera）

相机驱动 + 看图 + 内参标定。对应包 `rb_camera`。

---

## 1. 硬件（本机实测）

```
USB 2.0 Camera: HD USB Camera    ID 05a3:9230
  /dev/video0    ← 采集节点（用这个）
  /dev/video1    ← metadata 节点（别用）

支持格式：
  MJPG  1280x720@60  1920x1080@30  640x480@120 ...
  YUYV  1280x720@9   1920x1080@6   640x480@30   ← 高分辨率下极慢，必须用 MJPG
```

这是 **UVC 免驱 USB 摄像头**（不是海康工业相机），不装 `/opt/MVS` SDK。

---

## 2. 发布话题

| 话题 | 类型 | 说明 |
|---|---|---|
| `/camera/image_raw` | `sensor_msgs/Image` | 原始图（bgr8） |
| `/camera/image_raw/compressed` | `sensor_msgs/CompressedImage` | **JPEG 压缩图（实际用这个）** |
| `/camera/camera_info` | `sensor_msgs/CameraInfo` | 内参 |
| `/rb_camera/ok` | `std_msgs/Bool` | 是否在出图 |

驱动做了三件 UVC 相机必须处理的事：
1. **MJPG 协商**：`FOURCC` 必须在设分辨率**之前**下发，否则 720p 掉到 9fps。
2. **独立采集线程**：持续抓帧、只留最新一帧，处理慢也不积压、不延迟。
3. **掉线自愈**：连续读失败就 release 重开，拔插自恢复。

---

## 3. ⚠️ 大图吞吐瓶颈 → 必须用 JPEG 压缩

原始图投递带宽上限约 **7 MB/s**，帧率随分辨率崩塌：

| 分辨率 | 每帧 | 原始投递 | JPEG 压缩后 |
|---|---|---|---|
| 320x240 | 230 KB | 30 fps | 30 fps |
| 640x480 | 921 KB | 5~11 fps | **30.6 fps** |
| 1280x720 | 2.7 MB | 4~7 fps | **25.6 fps** |

JPEG（q=80）把 720p 压到 ~55KB，30fps 只需 ~1.7MB/s。**`publish_compressed: true` 必须保持开**（`camera.yaml`）。感知端默认订阅压缩话题。

> 雷达点云同样是大消息，若 FAST-LIO 上不去，优先怀疑同一类吞吐问题。

## 4. 启动与看图

```bash
rbws

# 起相机
ros2 launch rb_camera camera.launch.py

# 看图（OpenCV 弹窗，无需装 rqt）
python3 tools/view_camera.py              # 实时画面 + 检测框
python3 tools/view_camera.py --raw        # 原始图（720p 帧率低属正常）
python3 tools/view_camera.py --duration 6 --save /tmp/shot.jpg   # 存图
# 快捷键：q/Esc 退出  s 存图  d 切换检测框
```

自检：

```bash
python3 tools/camera_check.py             # 出图率 + 内参 + 存快照
python3 tools/vision_rate_check.py --sweep  # 相机 vs 感知吞吐
```

## 5. 内参/畸变标定（测距的前提）

`Detection.distance_m = fx × 真实直径 / 像素宽`，所以必须标定。**当前已标定**：

```yaml
# camera.yaml / perception.yaml
fx: 794.16   fy: 793.9   cx: 577.4   cy: 378.38
distortion: [0.018392, -0.525673, 0.015934, 0.004543, 0.808854]
```

标定工具（自研，不依赖 `camera_calibration`）：

```bash
# ① 生成可 1:1 打印的棋盘格（精确 A4，方格 20mm，9x6 内角点）
python3 tools/calibrate_camera.py --pdf --out ~/chessboard_A4.pdf
#    打印务必选【实际大小/100%】，别"适应页面"；打完量方格是不是 20mm

# ② 采集 + 标定（窗口里有清晰度读数，离太近会提示"严重模糊"）
python3 tools/calibrate_camera.py --auto     # 自动采集（按位姿去重）
#    目标 15~25 张：远/近、四角、左右倾斜都要有
```

- 质量判定看 RMS：< 0.5 px 好，> 1.0 px 重来。
- **`--probe`** 能识别"打印被缩放后实际是多少格"，不用重印。
- 结果自动写回 `camera.yaml` + `perception.yaml`（感知读后者）。

**去畸变会真正参与计算**：35° 离轴误差从 60 mrad（3.44°）降到 0.04 mrad。3.44° 在 3m 处是 18cm 横向偏差——瞄准投/传是按方位角开环对准的，不标定会一直偏。

> 必须在**生产分辨率**（1280x720）下标定。换分辨率要重标。

## 6. 锁定曝光/白平衡（颜色稳定）

HSV 阈值对光照敏感，自动曝光/白平衡一动，同一颗球的 S/V 就漂。要锁死：

```bash
# 先停掉 rb_camera（同一设备不能被两个进程用）
python3 tools/tune_camera.py     # 拖滑块实时调  s=写回  a=自动/手动对比  q=退出
```

驱动每次开相机自动应用 `camera.yaml` 的 `controls:` 段并**读回确认**：

```
相机固定项已应用: 自动曝光→手动, exposure_time_absolute=30, 自动白平衡→关, 色温=4600
```

⚠️ 这台相机自动模式下曝光/色温带 `flags=inactive`，**读不到自动值**，只能人工定。
换场地/灯光后重跑 `tune_camera.py`（颜色标定也会受影响）。
