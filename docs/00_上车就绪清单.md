## 到车边第 1 件：CAN + 底盘

```bash
sudo ip link set can0 down 2>/dev/null
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 txqueuelen 20          # ⚠️ 不能省
sudo ip link set can0 up
ip -details link show can0                    # 要看到 UP / ERROR-ACTIVE / 1000000 / qlen 20

source /opt/ros/humble/setup.bash && source install/setup.bash
ros2 launch rb_chassis chassis.launch.py
```

**量尺寸 → 用工具实测（别靠猜）**

当前配置里是 `width=0.65 / length=0.40 / wheel_radius=0.0375`，
其中**两处仍有歧义**必须实测确认：

| 参数 | 现状 | 待确认 |
|---|---|---|
| `width` | 0.65 | 这是**车体宽**还是**轮距**？代码要的是左右轮**中心**距 |
| `length` | 0.40 | **未提供**，占位值，必须量 |
| `wheel_radius` | 0.0375 | 按"直径 7.5cm"折半；若 7.5cm 是半径则应为 **0.075** |


## 一页速查：出问题先看哪里

```
车不动
├─ /cmd_vel 有数据吗
│   └─ 没有 → /mission/status 卡在哪个阶段？该阶段在等定位还是视觉？
├─ 有数据但不动 → can0 起了吗？txqueuelen=20 吗？
└─ 动但方向不对 → 尺寸参数没量对

定位飘
├─ /localization/ok 是 true 吗
└─ 绝对观测量有没有生效（abs_pose_topic 或 landmarks）

视觉看不到
├─ /perception/debug_image 里能看到目标吗
│   ├─ 看得到没框 → 颜色阈值（重标定）
│   └─ 看不到     → 相机曝光/视野，不是算法问题
```
