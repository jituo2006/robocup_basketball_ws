# 05 · 定位模块（rb_localization）

EKF 融合里程计 + 绝对位姿 + 视觉方位角。对应包 `rb_localization`。**⚠️ 尚未上车调通。**

---

| 方案 | 合规性 | 现状 |
|---|---|---|

---

## 2. 配置（`localization.yaml`）

```yaml
sources:
  odom_topic: "/Odometry"        # 雷达 FAST-LIO 位姿（注意大写 O，不是底盘 /odom）
  use_odom_pose_as_abs: true
  abs_pose_topic: ""             # 留空 = 不用外部绝对位姿
  detections_topic: "/perception/detections"
  camera_yaw_offset_rad: 0.0     # 相机光轴与车体前进方向夹角，要标定
output:
  pose_topic: "/localization/pose"
  ok_topic: "/localization/ok"
```

⚠️ **`landmarks` 当前为空** → 视觉方位角更新**不会生效**（EKF 收不到观测）。
需按本轮定位柱实际坐标填：

```yaml
landmarks:                       # 定位柱在场地坐标系的坐标
  - {x: 3.5, y: 2.0}
```

## 3. EKF（`ekf2d.py`）

- 状态：`[x, y, yaw]`，预测用里程计，更新用绝对位姿/视觉方位角。
- **修过 H 矩阵符号 bug**：`update_bearing` 里曾把观测雅可比写反，估计发散
  （跑到 (10.2,4.7) vs 真值 (0,-1)）。现为 `[[dy/d², −dx/d², −1]]`，有回归测试锁住。
- 本队约定 **yaw 塞在 position.z** 里（底盘 `execute()` 读的也是 z）。

## 5. 验证

```bash
ros2 launch rb_localization localization.launch.py
ros2 topic echo /localization/pose        # 推车时 x/y/yaw 跟着变
ros2 topic echo /localization/ok          # 应为 true

# 雷达回放专项验证（用真实 rosbag）
python3 tools/verify_lidar_replay.py
```

验收：
- [ ] 静止 30 秒漂移 < 5cm
- [ ] 推车走一圈回原点，误差 < 20cm
- [ ] 定位柱进入视野后误差明显收敛
- [ ] 推到已知点，x/y 与卷尺一致（不一致 = 坐标系原点/朝向定义问题，先解决再上任务）

## 6. 相机方位角偏置标定

`camera_yaw_offset_rad` = 相机光轴与车体前进方向夹角。

标法：把车摆正对着一个已知方位目标，看 `bearing_rad` 与理论值差多少，填差多少。
