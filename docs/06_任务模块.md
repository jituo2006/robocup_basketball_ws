# 06 · 任务模块（rb_mission）

任务状态机 + 导航 + 避障 + 场地几何。对应包 `rb_mission`。

---

## 1. 状态机流程

```
IDLE → START_DELAY（5~15s 规则要求）→ SEEK_BALL → ACQUIRE → NAV_TO_ZONE
     → ALIGN → LAUNCH → RETURN_HOME →（下一环节）
```

- `mission`（PASS/SHOOT）决定谁当**目标球**、谁当**干扰球**：
  传球环节目标=ball_basketball、干扰=ball_volleyball；投篮环节互换。
- 目标/干扰由 `mission_labels`（`mission.yaml`）配置，YOLO 只负责输出两类，角色由状态机定。

---

## 2. 场地几何（已按 2025 规则填入，待 2026 场地图复核）

坐标约定：x 沿 14m 长边，原点在**远离篮筐**的底线；y 沿 7.5m 短边，y=3.75 是中线；
yaw=0 指向 +x（朝篮筐）。

| 字段 | 值 | 来源 |
|---|---|---|
| 场地 | 14.0 × 7.5 | 【规则正文】 |
| `hoop` | {12.425, 3.75} | 【推导】篮筐中心距底线 1.575m（FIBA）→ 14−1.575 |
| `shoot_line_radius_m` | 2.0 | 【规则正文】投篮边界线，圆心=篮筐 |
| `three_point_radius_m` | 3.75 | 【规则正文】 |
| `three_point_center` | {11.0, 3.75} | 【规则正文】"右侧底线中点向场内 3m"，**不是篮筐** |
| `shoot_zone_target` | {9.5, 3.75} | 【推导】待复核 |
| `shoot_zone_target_30` | {7.0, 3.75} | 【推导】待复核 |
| `home` | {1.0, 1.0} | 占位，实测 |
| `pass_zone` / `pass_zone_target` | 占位 | 【待场地图】 |

> ⚠️ **三分线圆心不是篮筐**。规则说"右侧底线中点向场内 3 米点"为圆心，
> 与篮筐差 1.425m。`is_three_point()` 已修：优先读 `field.three_point_center`，
> 缺配置才退回篮筐（兼容旧配置）。以前用篮筐当圆心会把 30 分档判错。

拿到 2026 场地示意图后，把【待场地图】的占位值逐项实测替换。

## 3. 导航与避障

- **go-to-pose 服务**：`/rb_mission/goto_pose`（`GotoPose.srv`）。
- **点地图操控**：`python3 tools/click_goto.py`。
- **视觉势场避障**：订阅 `/perception/detections`，把当前环节的干扰球/障碍物换算成
  排斥速度叠加。参数在 `mission.yaml` 的 `avoidance:` 段。

```bash
ros2 service call /rb_mission/goto_pose rb_msgs/srv/GotoPose "{x: 5.0, y: 3.0, yaw: 0.0, align_yaw: false}"
```

## 5. 状态机调参（`mission.yaml`）

| 参数 | 作用 | 调不好会怎样 |
|---|---|---|
| `max_linear` / `max_angular` | 速度上限 | 太大过冲/撞球，太小超时 |
| `kp_linear` | 走位增益 | 太大振荡，太小到点慢 |
| `kp_yaw` / `yaw_tolerance` | 转向/对准 | 抖动 vs 对不准 |
| `position_tolerance` | 到点判定 | 永远到不了 vs 没到位就动作 |
| `close_lost_distance_m` | 球近此距离后消失→视为已吸到 | 太大误判，太小贴上去还不判 |
| `state_timeout_s` | 单阶段超时 | 太小动作没做完就重试 |
| `start_delay_s` | 启动延迟 | **规则要求 5~15 秒，不能改出范围** |

调参纪律：一次只改一个，记下改前/改后。
