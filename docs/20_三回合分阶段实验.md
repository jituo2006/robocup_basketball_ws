# 三回合分阶段实验

依据 2026 修订规则 PDF 第 9、10 页；未改动的流程和几何按用户指定沿用 2025，第 7、10–13 页。2025 第 10 页传球、第 12 页投篮都明确：**A/B 是每个回合的起始区域**。因此不是第一回合结束后直接在场内开始第二回合；每次回合启动前重新放回本方出发区。一个回合内的两次取球/出球连续进行，不在两次动作间重新开一轮。

本版只做 A 区。车初始面向篮筐、平行中线。程序把启动时的实际位置/朝向对应到名义 S=(1.5,8.0,0)，不修改定位数据，也不要求雷达初始坐标恰好是零。物理上必须摆在 A 区：在其它位置点按钮仍会把该位置当作本轮起点，路线会整体偏移。

## 入口与参数

- 程序入口：`tools/test_perimeter_ball.py --route round1`、`--route round2`、`--route round3`。
- 路线实现：`tools/match_round_route.py`，`RoundRoute.execute()`。
- 场地坐标、行驶速度、搜索轨迹、区域后退距离、瞄准点和出球指令：`tools/match_rounds.json`。
- 前端：固定路线实验下面的“三回合分阶段实验”；选传球/投篮、实验范围，再点对应回合。每轮各有阶段按钮。每步停车后才进入下一步；第1步重新建立起点，后续步骤复用它。靠近距离、速度、吸球开关在展开参数中，下次启动生效。

| 实验范围 | 实际执行 |
|---|---|
| `drive` 空场走路线 | 走本环节优先搜索轨迹→动作点→回本轮起点；不读取目标球、不吸球、不出球 |
| `collect` 默认 | 第1回合送预装球到动作点停车；第2/3回合找一球、对正吸球、到动作点停车并保持机构 |
| `cycle` 双次流程 | 第1回合先处理预装球、再取中线球；第2/3回合取两颗。每次到动作点放球/出球，最后回位。默认 `drop` 是放球联调；正式 `match` 出球必须先配置 `commands` 和 `aim` |

吸球已由用户确认成功：`STOP → ZERO → MOVE 1 90 5`；放球只发 `MOVE 1 0 5`，不追加STOP、ZERO。新三回合流程吸球成功后保持机构，到动作点的放球阶段才下发放球；原单次固定路线按钮保持原来行为。

代码运行结束只说明动作流程执行完成。当前没有可靠入仓、持球、实际出球反馈，所以不能凭脚本返回成功宣称获得比赛分数。空场路线模式须在球已清开的场地测试。

```bash
ssh user@10.21.231.58
cd /home/user/robocup_basketball_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=2
# 先启动底盘、雷达定位、前后摄；路线命令会接管并停止旧任务节点。
python3 tools/test_perimeter_ball.py --route round2 --round-task pass --round-mode drive --takeover --yes
python3 tools/test_perimeter_ball.py --route round3 --round-task pass --round-mode collect --takeover --yes
# 投篮环节把 --round-task pass 改成 --round-task shoot；此时找排球。
```

两个命令是分别选择的实验，每次新开一回合重新摆车，不要当作连续脚本一起执行。分步入口为 `--round-step N`，例如 `--route round1 --round-task pass --round-step 1 --takeover --yes`；下一步保留其余参数，改成阶段2。后续阶段不重新摆车，不重置定位。

## 第一回合分阶段

启动前预装一颗本环节目标球。9个阶段为：

1. 静止5秒、右转90°、到入场点E。
2. 带预装球到传球P/投篮Q。
3. 放预装球（联调）或正式出球。
4. 中线横扫找第二颗目标球；第一回合没有其它置球区的兜底。
5. 停车点转180°，后摄横移对正，**只对正，不靠近**。
6. 保持刚才的方向低速靠近，执行吸球，不再要求YOLO。
7. 保持吸球，沿来路退出、到动作点。
8. 第二次放球（联调）或正式出球。
9. 回A区，恢复面向篮筐。

后摄对正和靠近吸球拆开，便于分别检查“已经对正但没走”和“靠近过头”。中途靠近失败后重试只补剩余位移，不会再走完整配置距离。每步运行状态暂存在 `/tmp/rb_match_rounds`，用于跨按钮保留起点和下一阶段；这不是比赛成功记录。第1步重开会使旧阶段失效。

## 第二回合怎么走

1. S=(1.5,8.0)，朝 +X；静止5秒，右转90°。
2. 经 E=(1.5,6.8)，前进到 C=(1.5,4.8)，合计3.2米。
3. 前摄朝 −Y，沿 Y=4.8 横移：X=1.5→4.4；没有球就反扫到0.6。回合内第二次搜索换向：1.5→0.6→4.4。
4. 目标到画面中心即停、转180°，后摄横移居中，然后向球低速后退。传球目标篮球，投篮目标排球。
5. 回到检测点，再沿已经走过的折线回 E。传球经 C 到 P=(3.6,4.5)；投篮经上侧 T=(6.4,6.8) 到 Q=(6.4,4.8)。单次模式停在这里并保持吸球；分步模式下一阶段放球。
6. 中线没有目标时，经 E、T 补扫三分弧。不能假定两队共享的2颗中线球一定留给本方。
7. `cycle` 模式放球联调或配置后的正式出球一次，再取第二颗、出球，最终经 E 回 S；不会在两次取球间回 S 重置路线。

2026 配置：中线目标/干扰=2/0；绿线=0/4，只有干扰；三分弧=3/2。不在绿线找目标球。

## 第三回合怎么走

第三回合中线没有球，直接 S→E→T，不执行中线横扫。

- **传球**：先扫三分弧（2篮球/2排球），没有篮球再扫内侧 X=9 置球线（3篮球/1排球）；取球后沿来路退出，回左侧 P 传球点。
- **投篮**：先扫内侧 X=9 置球线（3排球/0篮球），没有排球再扫三分弧（4排球/2篮球）；取球后退出，到 Q 投篮点。

三分弧搜索：车心以 (11,3.75) 为圆心、半径4.65米，按160°→170°→180°→190°→200°分段走，每段调整前摄朝向圆心。这个近侧弧段没有覆盖整条三分线；找不到换内侧搜索，不承诺扫描完整场地。

内侧搜索：车心 X=8.2，前摄朝 +X，沿 Y=6.2→1.3 平移。第二次扫描方向反过来。只写死观察路线，目标球的实际位置仍靠视觉发现。

第二、三回合均为12个阶段：入场 → 第一颗搜索/转身对正/靠近吸球/持球到动作点/放球 → 第二颗同样5步 → 回位。

`cycle` 执行两次取球/放球或正式出球指令后经 T、E 回 S。2026 已取消旧版“三分线外才能取球”的限制，可以进入三分区取球。

## 初始参数及接下来要调什么

| 参数 | 初值 | 调试内容 |
|---|---:|---|
| 普通行驶/横扫上限 | 0.25 m/s | 检查移动方向、里程和转向；末端随剩余距离减速 |
| 吸球靠近上限 | 0.08 m/s | 确认低速能克服底盘摩擦 |
| 中线后退 | 0.40 m | 沿用当前实验值；看球能否进入机构 |
| 三分弧后退 | 0.25 m | **试验初值，不是测距结论**；先测车心、摄像头、吸球口到球的关系 |
| 内侧线后退 | 0.15 m | **试验初值**；观察线离球更近，因此先用较短行程 |
| 前摄中心带 | ±4%画面宽度 | 是否停车及时，是否选错干扰球 |
| 后摄中心带 | ±2.5%，3个不同新帧 | 横移左右符号、对准稳定性 |

后退靠近只用定位位移，不继续要求 YOLO；YOLO 用于寻找目标和后摄横向对正。雷达提供位姿、里程计，未把未经确认的雷达球距当成精确后退距离。

后续依次补充：

1. **空场路线与取球距离**：每轮重新摆车，验收上下侧方向、通道宽度、180°转向以及三处实际吸球距离；确认保持吸球时回撤不会掉球，动作点的放球能让球确实离开机构。
2. **机构出球和瞄准**：提供成功过的传球、投篮文本序列；写入 `release.pass/shoot.commands`。传球架坐标需实测填 `aim`，投篮默认篮筐坐标只是场地规划值。不能用吸球 `MOVE 1 90 5` 或停吸球 `MOVE 1 0 5` 冒充出球。
3. **入仓/出球反馈和目标关联**：确认球已入仓才转运，实际出球后才计一次。防止再次追同一颗未吸进的球；靠近有多颗同类球时保持同一个目标。
4. **干扰球避让**：本版保留用户当前的“避障关闭”。上侧 Y=6.8 是候选走廊，车身通过绿线端部、进入内侧时可能遇球；在带完整干扰球的场地跑之前，需要恢复并调好绕行，或修改已实测净空的通道。不能认为“绿线全是干扰球”就可以直接穿过它们。
5. **时长、动作点和回位**：Q 到篮筐约6.1米，需要射程校准，必要时改较近动作点。当前绕回通道与0.25速度可能超过120秒，尤其第三回合传球；实测后缩短往返，不能当作已经满足比赛时限。S中心到位还需确认全部承重轮在1×1米出发区。
6. **比赛启动**：网页用于实验。正式比赛按2026第7页改为本机开关触发，保留5–15秒静止延迟，完全自主运行；移动篮筐需实时识别瞄准。

本次添加可执行实验程序、33个分步按钮、连续运行入口和配置，没有启动机器人运动。放球联调不能替代评分要求的有效传球/投篮；自动发射与入仓/出球反馈仍待接入。
