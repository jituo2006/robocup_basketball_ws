# 09 · 底盘 CAD 尺寸核查

2026-10-09，根据用户提供的 `篮球车-整装.zip`，核对底盘与全向轮的设计几何量。
本次更新参数与 C++ 默认值；尚未进行实车标定，不代表点选移动的停车误差已经解决。

## 1. 代码采用的几何初值

| 参数/几何量 | CAD 结果 | 代码单位 (m) |
|---|---:|---:|
| `wheel_radius` | 外径 153 mm，半径 76.5 mm | `0.0765` |
| `width` | CAD X 方向轮心间距 477.059538 mm | `0.477059538` |
| `length` | CAD Z 方向轮心间距 477.059538 mm | `0.477059538` |
| `hypot(width/2, length/2)` | 底盘中心到轮心 337.332034 mm | `0.337332034` |

这些值已同步到 `chassis.yaml`、底盘节点的 ROS 参数默认值和底盘基类的成员初值。
`ratio`、电机编号、方向、CAN 设置、限速及命令超时保持原有设置。

## 2. 测量依据

- 从 `篮球车-底座.SLDASM` 的 `swXmlContents/COMPINSTANCETREE` 读取装配层级及变换矩阵。
  数据流解压后核对声明长度与 CRC。沿“底座 → 万向轮模块 → 全向轮装配 → 导入轮子”组合变换。
- 轮心采用 28 个滚子中心的轴向中面：两排滚子局部 Y 分别为 1.5 mm、21.5 mm，
  因此轮心局部坐标为 `(0, 11.5, 0) mm`，而不是零件坐标原点。
- 直接读取 `R2_OTOW-全向轮装配.STEP` 的精确曲面。OCCT 计算的 X/Z 外包络均为
  `[-76.5, +76.5] mm`；曲面网格径向距离复核最大值为 `76.50000000000009 mm`。
- 四轮等高、轮轴水平且径向分布；四个轮心形成正方形，四边均为 477.059538 mm，
  两条对角线均为 674.664069 mm，四个中心力臂均为 337.332034 mm。

CAD 的竖直方向为 Y，水平面为 XZ。以下坐标以四轮中心的平均值为底盘中心，单位 mm。
“实例号”只表示 CAD 装配实例，不能直接当成电机编号。

## 3. 实车验证

1. 重建/同步安装目录并重启节点，确认实际加载的新参数，避免修改源码配置后仍加载旧安装文件。
2. 核对车头坐标系、四轮电机编号与方向，再低速验证前后、横移和旋转。
3. 用 `tools/measure_chassis.py` 标定有效滚动半径及转向比例；设计半径不包含轮子变形、磨损和打滑。
4. 按实际定位延迟和制动距离验证点选停车。尺寸更正不能单独证明“走过头”已经解决。
